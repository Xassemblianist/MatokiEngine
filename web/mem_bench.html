7. memory64 Chrome Bayrak Durumu Raporu

Tespit ediliyor...
  • Teknoloji: WebAssembly Memory64 Proposal (64-bit doğrusal bellek indeksleme).
  • Chrome Bayrağı: --js-flags="--experimental-wasm-memory64" veya chrome://flags/#enable-webassembly-memory64.
  • Standartlaşma: W3C Phase 3 (Chrome 105+, Firefox 131+, Node.js v18+).
  • L0 Mimari Değerlendirmesi: 4 GB sınırı tamamen kalkar. Ancak 64-bit işaretçiler bellek ayak izini %20–30 artırır; MATOKI'nin işaretçisiz 32-bit ofsetli veri modeli (ARCH_V2 §2) ile bu kayıp bertaraf edilir. Faz 0 için varsayılan wasm32 + 1 GB SAB önerilir.
